# HAK Smart OCR AI — Windows Build (isolated branch)

This directory is reserved for the **HAK Smart OCR AI** standalone Windows desktop application.

- Branch: `feature/hak-smart-ocr-ai-windows`
- Project directory: `apps/hak-smart-ocr-ai/`
- Payroll source on `main` is untouched.
- The source ZIP prepared outside GitHub must be extracted here before the Windows build workflow can run.
- Do not commit employee photographs, payroll documents, screenshots of conversations, secrets, or private financial information.
- The **default** build provides Tesseract OCR with bundled Vietnamese and English language data. PaddleOCR, Docling, handwriting models, and advanced AI weights are **not** part of the core installer until separately verified and bundled.
- Do not consider any generated EXE production-ready until build self-test and real Windows clean-machine acceptance are completed.

**Current status:** branch scaffold only. Source and Windows installer are not yet uploaded/built.

Source package: HAK_Smart_OCR_AI_1.2.0_GitHub_Ready_Project.zip (previously prepared for user).
