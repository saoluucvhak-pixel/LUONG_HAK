# HAK code quality test skill
1. Inspect exact repo/branch, manifests, tests and critical workflows.
2. Inventory security, access control, cache, sync, accounting rounding, exports, UI and offline recovery risks.
3. Run static checks; classify findings as suspected until reproduced.
4. Execute existing tests and report exact command, result and environment.
5. Add unit/integration tests for core business invariants and permission scopes.
6. Test browser UI with Playwright, desktop UI with platform-native tools; inspect overlap and export parity.
7. Audit accounting report dates, 0–6 fractional digits, unlimited integer-string formatting, MT/BDMT and moisture/dryness precision.
8. Report P0–P3 with file/line, reproduction, impact, patch and regression tests.
9. Never change main, leak PII or test against production money/credentials.
10. Distinguish implemented, executed, and verified; do not invent test outcomes.
